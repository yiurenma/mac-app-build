# v0.7.2 — GMX 复选框标签遮挡修复

现场日志显示 SYNC_UPLOAD 输入可见且启用，但 `label.attach-previous` 拦截鼠标点击，造成 check 超时，正式 Build 尚未创建。

## 修复

- 先核对当前勾选状态；符合要求则不再次点击。
- 使用常规 check/uncheck，短超时后只查找当前输入通过 labels 或紧邻 attach-previous 关联的唯一可见标签。
- 点击该标签后回读 is_checked；禁用输入、无法唯一关联、状态不一致时停止。
- 不使用强制点击，不穿过无关遮挡层；适用于 SYNC_UPLOAD、SKIP_TEST、FORCE、KEEP_ALIVE。
- 保留 Bootstrap 测试及正式 Build 编号出现即返回的 v0.7.1 行为。

## 验证
