## 验证边界

执行环境未能读取四张 Library 参考图（网络代理拒绝下载）；需求已由父任务实际检查并转述。本次沿用现有深色 UI，不声称进行了参考图像素比对。已在本环境运行页面并检查实际桌面/移动截图。

浏览器回归运行真实 localhost HTTP 服务、SQLite 与 Chromium；GitHub 分页使用模拟响应，手动构建提交使用替身，不触发企业 GitHub/Jenkins。离线 Jenkins/Nexus 测试使用模拟日志或 DOM。未连接公司 VPN、未验证真实 SSO、内网产物或真实上传；未在用户 Mac 安装 LaunchAgent、启动持久服务或触发构建。

仓库质量门禁：`./selftest.sh` 连续三轮全量 unittest、Python 编译、Shell 语法与 CLI dry-run；另检查两个 JavaScript 文件语法和 `git diff --check`。日志保存在 `docs/verification-logs/round1.txt` 至 `round3.txt`。GitHub Actions `Offline regression` 在 main push/PR 上重复这些离线检查，并保存测试日志与 UI 截图。

`upload_success_pattern` 归入「更多 GMX 设置」，保留原行内说明和共用序列化；浏览器回归断言该字段只在 GMX 组，并以非空规则验证计划保存、编辑及立即构建的完整往返。`CUSTOM_FOLDER` 的原占位文字 `0_A_<国家>_<项目>` 经浏览器实际展开后读取确认正常显示，保留原文，没有认定其为显示缺陷。本地 4 项 UI、9 项高级参数、25 项定时相关测试通过；最终提交的全量三轮结果见该提交的 Actions。
