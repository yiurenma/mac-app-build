# v0.6.3 — Web Console 默认输入参数补齐

## 常用与高级分组

- 常用：Plugin/GMX 源分支、Plugin 大版本、Country/ENTITIES、Project Name、凭据与可见浏览器/详细日志。
- 高级 A：Plugin/GMX GitHub 源仓库地址。
- 高级 B：Plugin/GMX Jenkins Job 父级 URL、浏览器 channel、只读全局最大并发数。
- 高级 C：GMX BUILD_TYPE、SIGNING_REPO_BRANCH、CUSTOM_FOLDER、SYNC_UPLOAD。默认取 `config.yaml` 的 `jenkins.gmx_defaults`；CUSTOM_FOLDER 为空时自动生成 `0_A_<COUNTRY>_<PROJECT>`。用户手动编辑后不再自动覆盖。
- 高级 D：Job 发现间隔、Build 状态间隔、Console 日志结束标记等待、Job/Build/Callback 超时、最大提交行数、GMX 上传完成日志正则。
- 高级定位器：ENTITIES、SYNC_UPLOAD、CUSTOM_FOLDER、BUILD_TYPE、SIGNING_REPO_BRANCH 的可选 CSS 选择器。

## 真实执行与隔离

- `/api/bootstrap` 只返回非敏感默认参数；用户名、密码、Token 不回传。前端用 `textContent` 和表单 value 渲染，不动态写 HTML。
- `/api/tasks` POST 先验证值、URL、轮询范围、正则、Jenkins 参数，再创建任务。Github/SSO 密码仍存 Keychain。
- `store.create_task` 使用本任务的 Jenkins Parent URL 来生成 Plugin 和 GMX Job URL。`runner.effective_task_config` 每次启动/恢复从当前配置构造任务专属设置，不覆盖全局配置。
- GMX 参数提交使用 Playwright 的 select_option / fill / check / uncheck，并验证修改后实际控件值；Plugin Jenkins 其他参数原样保留。
- 新任务创建时所有高级参数持久化；断点恢复复用；不同并发任务互不覆盖。

## 注意事项

- 已知 Jenkins 参数均已覆盖，但如果 GMX Jenkins 还存在新的/内部定制的输入项，需要先确定对应字段名称与期望行为，再增加新的严格验证项，不会盲填未知字段。
- `SYNC_UPLOAD=false` 时 Jenkins 构建成功不代表自动上传成功。
- 页面启动只在 Mac localhost：`http://127.0.0.1:8765`。不连接公网 CDNs。
- 此版本通过离线 HTTP、数据库和 Playwright 控件模拟测试，尚未在公司实际 Jenkins/SSO 上执行端到端构建。
