# v0.6.8 — GMX Jenkins 运行模式适配

## 截图确认的实际行为

- GMX Job: `mobilex-global-uploads/global-ios-upload/upload%2FUKPBB-203745-V2`。
- 首次 #1：`Build disabled: ENTITIES or BUILD_TYPE is empty`。这是初始化中的禁用构建，不应要求首次成功；必须等参数化入口出现。
- 正式 #2：直接 `Build with Parameters` 并在相同 Build 编号的 Stage View 显示成功，没有 Plugin 的 Manual Callback。
- 当前 Jenkins 参数 UI：ENTITIES（文本）、SKIP_TEST（选中）、FORCE（选中）、KEEP_ALIVE（未选中）、SYNC_UPLOAD（未选中）、BUILD_TYPE（Develop）、CUSTOM_FOLDER、SIGNING_REPO_BRANCH。
- Jenkins UI 的 SYNC_UPLOAD 帮助提示：false 会触发下游任务并在 Master 归档；按原业务要求，Mac APP Builder 仍默认强制勾选 true。

## 代码行为

1. GMX 初始化 #1 被禁用时，只等 `Build with Parameters` 出现，不再等待 #1 的最终 Console 或把它当正式结果；本次是否正式完成仅取正式编号。
2. 提交前明确填 ENTITIES、SYNC_UPLOAD、CUSTOM_FOLDER、BUILD_TYPE、SIGNING_REPO_BRANCH，并按任务自定义调整 SKIP_TEST、FORCE、KEEP_ALIVE；对类型和填写后状态进行校验。
3. GMX 的正式 Build 独立检查对应编号的成功图标、详情页、Console，不调用 Plugin Callback 关联。
4. SYNC_UPLOAD=false 时，GMX Build 成功不代表下游 Upload 完成，报告 `DOWNSTREAM_UPLOAD_NOT_VERIFIED`；无正则校验时不宣称已独立验证上传。

本版本经过离线模拟，真实公司 Jenkins 参数 DOM、SSO、下游上传尚待现场确认。
