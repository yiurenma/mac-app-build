# v0.7.1 — GMX 独立测试边界

## Bootstrap Test（只测试到 bootstrap 完成）

- 必填 GMX 分支：例如 `upload/UKPBB-203745-V8`。
- 必填 **完整 Plugin Artifact Version**：例如 `1.3.1-alpha.1-SNAPSHOT.2`。不是 Plugin 的 `1.3` 主次版本，也不是 GMX 分支号。
- 使用独立的 shallow clone，原始 `mobile-ci.lock` 作为校验基线。
- 仅将 `mobile-ci.json` 中 `PayByBankDomainModelPluginKit` 和 `PayByBankJourneyPluginKit` 的版本替换成输入的完整版本号，再执行 `./bootstrap.sh`。
- 验证 `mobile-ci.lock` 中两个目标依赖版本和 SHA256 都正确，其他依赖内容保持不变；如果多出非目标文件变更则 FAIL。
- 不执行任何 Git commit/push 或 Jenkins Build；输出沙箱目录，供排障检查。

## GMX Jenkins Build Test（只测试到第二次 Build 启动）

- 先检查 Job 当前入口。无参数时才触发初始化普通 Build，并等待参数表单出现；已有参数表单时跳过初始化。
- 按页面填写参数后点击 Build，并等它分配正式 Build Number。
- 一旦发现编号，立即返回 PASS / TRIGGERED、Build Number 和 Build URL。**TRIGGERED 不代表构建 SUCCESS，也不代表上传完成。**
- 完成后的真实状态继续使用只读的 `GMX Jenkins URL Test` 检查，不重跑 Bootstrap。
