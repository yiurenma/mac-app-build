# v0.6 Web Console 验证报告

- 基线：v0.5.0 CLI/Plugin/GMX/Jenkins 工作流保持兼容。
- 本次新增：macOS 双击启动入口、本地 HTTP 服务、Web Console 前端、真实任务历史/日志/截图/恢复接口、GitHub PAT Keychain、输入验证、CSRF + Host 防护、有限日志读取。
- 三轮独立完整离线回归：**106 / 106 PASS、106 / 106 PASS、106 / 106 PASS**。
- 每轮还检查：`compileall`、`sh -n`、`bash -n`、Node JS 语法，以及 `--dry-run`，均通过。
- 新增 tests: `tests/test_web_console.py`、`tests/test_web_github_keychain.py`。
- HTTP 验证使用真实绑定 loopback 的 ThreadingHTTPServer 和本地 HTTPConnection，不访问 Jenkins 或公网。
- 前端进行了 Chromium 静态渲染检查和截图；当前执行环境的 Chrome 对 loopback 页面导航应用了管理员阻止策略，因此**没有进行真实浏览器与本地 API 联调**。后端 HTTP API 和前端 JS 语法已分别验证，需在用户 Mac 上进行实际页面点击测试。
- Keychain 使用 mock 的 macOS `security` 命令检查参数和凭据路径；真实 Mac Keychain 系统弹窗、企业 SSO/MFA、Chrome 策略、公司 Nexus/Jenkins 的真实效果均需现场验证。
- 安全边界：限制本地端口、同源和 CSRF，不记录密码和 PAT 到任务 DB/浏览器持久存储。现有 Jenkins 与 Git 自身日志仍为尽力脱敏，分享前请人工检查。
