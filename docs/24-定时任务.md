# 定时任务（Schedules）

按 cron 表达式自动创建构建。**不改变任何现有构建流程**：到点时调用的就是 Web 页面「Start build」按钮背后的同一个 `create_build()`，所以参数校验、Keychain 凭据、环境检查、并发上限全部沿用。

## 使用

1. 运行 `./app-build web` 即会自动检查并启动独立后台调度器，复用同项目正在运行的手动或 LaunchAgent 实例。关闭 Web 后调度器继续运行。无需单独命令，也不会自动安装服务；只有需要登录 Mac 后自动运行时，才手动执行 `./app-build scheduler install`。
2. 打开 **New build**，填写同一份构建参数，开启「保存为定时任务」，填写名称与 cron；实时预览接下来 5 次运行。本机时区，默认最小间隔 30 分钟。Schedules 的新建和编辑也进入这个表单，所有高级值完整回填。
3. 列表里可以 停用/启用、立即运行、编辑、查看运行记录（可跳转到对应构建日志）、删除。

其他命令：`./app-build scheduler status | run | uninstall`。`run` 是前台运行（LaunchAgent 用它），调试时可手动执行。日志：`.appbuilder/scheduler.log`。

## 行为约定

| 场景 | 行为 |
| --- | --- |
| 电脑睡眠/关机期间错过了多次 | 醒来后**只补跑最近一次**，运行记录里注明"错过 N 次"。 |
| 到点时并发已满（`build.max_parallel`） | **排队，不丢弃**；有空位后按计划时间先后启动。定时和手动构建共用名额。 |
| 同一个时间点 | 数据库唯一约束保证同一计划时间不会重复入队；单实例锁阻止多个调度器同时启动。 |
| 启动失败（环境检查、Token 等） | 记录为 FAILED 及原因，不影响其他计划，下一个时间点继续尝试。 |
| 修改 cron / 重新启用 | 从当前时间重新计算，不补跑停用或编辑期间的时间点。 |
| 无人值守 | 与 New build 共用默认值：显示 Chrome。可在共用高级设置关闭 visible，隐藏模式需已有有效 SSO 状态。 |
| 最小间隔 | 默认 30 分钟（`config.yaml` → `build.schedule_min_interval_minutes`），避免误填 `* * * * *`；每次运行都会新建分支和 Jenkins 构建。 |

## cron 语法

5 段：分 时 日 月 周。支持 `*`、列表 `1,15`、范围 `9-17`、步长 `*/10`、`MON-FRI`、`JAN`，以及 `@hourly @daily @weekly @monthly`。日和周同时限定时按经典 cron 取"或"。时间为 Mac 本地时区。

## 安全

- 计划只保存**非机密**的构建参数模板；账号、密码、GitHub Token 一律拒绝保存，运行时使用 Mac Keychain 中已保存的凭据。
- GitHub Token 需要保存在 Keychain（在 New build 提交手动构建时保存；仅在输入框填写不会保存）。LaunchAgent 读不到终端里 `export` 的环境变量。
- 接口沿用现有的 Host / Origin / CSRF 校验，只监听 127.0.0.1。

## 限制

- Mac 睡眠或合盖时任何程序都不会运行（醒来后补跑最近一次）。需要不错过，请保持开盖并接电源。
- LaunchAgent 在用户登录后运行（需要读取 Keychain）；注销后不会触发。
- 每次运行都会创建新的 `release/…`、`upload/<工单>-auto…` 或 `upload/AUTO-<时间戳>` 分支和 Jenkins Job，暂无自动清理。

## Web 自动启动与排错

- 成功绑定 Web 端口后才后台检查；端口冲突不会启动调度器。多个 Web 通过启动锁协调，调度器运行锁保证只有一个进程实际调度。
- 沿用同一项目、`.appbuilder` 和绝对路径 `APP_BUILDER_CONFIG`。配置不同但已有持锁实例时明确报错，不终止它、不启动第二个实例；请先在原终端停止旧调度器。
- Web 每 15 秒检查一次；进程退出后可自动恢复。心跳文件残留不算在线，必须同时有活进程、运行锁和最近 60 秒心跳。持锁但心跳异常时仅提示，不冒险杀进程。
- 启动失败在 Schedules 显示原因与 `.appbuilder/scheduler.log` 路径。修复后自动重试。旧版调度器没有配置标记时仍可复用，建议方便时重启。
- 关闭 Web 仅停止检查线程，不影响调度器或 Worker。未安装 LaunchAgent 时，注销/重启后需重新打开 Web；Web 关闭期间不会自动恢复崩溃的调度器。
- 更新后请重新启动 Web、刷新页面。两个独立测试位于整页最底部，在左侧 **测试工具 → App 链接**；无需启用正式开关。邮件测试在 **Jira** 页面。
